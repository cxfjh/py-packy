# PyPacky - Python 打包工具

## 项目简介

PyPacky 是一个基于 Nuitka 的 Python 脚本打包工具，提供图形化界面，方便用户将 Python 脚本打包为可执行文件。

## 安装与运行

### 环境要求

- Python 3.12 或更高版本
- Nuitka

### 安装步骤

1. 克隆仓库：

   ```bash
   git clone https://github.com/cxfjh/py-packy.git
   ```

2. 进入项目目录：

   ```bash
   cd py-packy
   ```

3. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

4. 运行程序：

   ```bash
   python main.py
   ```
